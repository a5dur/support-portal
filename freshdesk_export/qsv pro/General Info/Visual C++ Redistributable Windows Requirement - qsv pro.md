# Visual C++ Redistributable Windows Requirement - qsv pro

If you're using a Windows device then you'll need Visual C++ Redistributable installed in order to use qsv pro.

If you've been redirected to this page while attempting to run qsv pro, then it's possible that you don't have Visual C++ Redistributable installed. The installation should start shortly and you may need to allow the Visual C++ Redistributable installer to run.

Alternatively you may download Visual C++ Redistributable from the following link and install it before attempting to run qsv pro: <https://aka.ms/vs/17/release/vc_redist.x64.exe>
